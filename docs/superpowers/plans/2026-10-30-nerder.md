# nerder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Wails desktop app that shows every Nerd Fonts family rendered in its real font on a syntax-coloured Go snippet, with one-click Install/Uninstall into the user's fonts directory.

**Architecture:** All font logic lives in Go packages under `internal/` (catalog, search, snippet highlighting, fetch/cache, install/uninstall) with no Wails imports, so a different UI (for example Qt) could reuse them. A thin `App` struct binds those packages to the Wails front end. The front end is plain JS/CSS (no framework) that lazily asks Go to download each family as its card scrolls into view and loads it with the `FontFace` API from a Go-served `/fonts/...` URL.

**Tech Stack:** Go (stdlib `go/scanner`, `archive/zip`, `net/http`), Wails v2 (WebKitGTK 4.1, build tag `webkit2_41`), Vite vanilla JS template, fontconfig (`fc-cache`).

**Spec:** `docs/superpowers/specs/2026-10-30-nerder-design.md`

## Global Constraints

- Linux only; Wails (WebKitGTK) UI; Go for all logic.
- Nerd Fonts release pinned to `v3.5.1`; `fonts.json` embedded as a snapshot from that tag (72 entries). The app uses the network only to download font archives.
- Archives: `https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/<folderName>.zip`.
- Fonts are fetched on demand (first time the card scrolls into view) and cached on disk under the XDG cache dir.
- Install location: `~/.local/share/fonts` (use `$XDG_DATA_HOME/fonts` if set). Run `fc-cache` after install and uninstall.
- Install copies every font file (`.ttf`, `.otf`) in the family's archive. The preview uses the Regular file (plus Bold if present) of the standard patched variant, never Mono or Propo.
- Installed state comes from the filesystem. A family found only system-wide shows "Installed (system)" with no Uninstall button. Uninstall removes the family's files from the user fonts dir, including hand-installed ones.
- Filters: fuzzy search on family name, installed only, monospaced (yes/no), license (`licenseId`). No ligature filter.
- UI: calm, clean, simple, elegant; fonts are the main thing on screen. Two switchable modes: List (one wide card per row) and Grid. After install, show a note that some terminals and editors need a restart.
- Wails will not follow the KDE theme, so the app brings its own design (light and dark via `prefers-color-scheme`).

## Review Focus

1. Network down or a download fails midway: the card shows an error with Retry, the app doesn't crash, and no half-downloaded family is left in the cache. (Task 5)
2. Hostile or odd archive contents (path traversal, directories, non-font files like LICENSE): only `.ttf`/`.otf` basenames are extracted, nothing escapes the cache dir. (Task 5)
3. `fc-cache` missing or failing, or the fonts dir doesn't exist yet: the dir is created, and a refresh failure is reported to the user while the installed files stay in place. (Task 6)
4. Similar family names (`Iosevka` vs `IosevkaTerm` vs `IosevkaTermSlab`, `Meslo` whose files start with `MesloLG`, names with spaces or `+` such as `Inconsolata LGC` and `M+`): uninstalling or detecting one family never touches another's files. (Tasks 2, 6)
5. Fast scrolling and double-clicks: many cards enter view at once, and Install is clicked twice. Downloads of one family are de-duplicated, total concurrent downloads are capped at 3, and a second Install is harmless. (Tasks 5, 6, 9)
